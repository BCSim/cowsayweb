A configurable talking (or thinking) cow, and friends. Type a message, pick a cowfile and a mode, and copy the result straight into a terminal, commit message or chat.

Mode default

Export as sticker

        
Chat apps set messages in proportional fonts, so pasted ASCII art loses its shape. The image export draws every character on a fixed grid, including Chinese, Japanese and Korean text at double width, so the cow looks the same in any app.

To make it a sticker, send the image in a chat, then long-press it and add it to your stickers or favourites. Browsers can only put still pictures on the clipboard. Copy GIF also adds the animated version as rich content, which Teams, Outlook, Slack and Gmail paste as a moving GIF. WeChat, WhatsApp and Line take only the still frame, so for those, save the GIF and send the file.
